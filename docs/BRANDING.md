# Logo

The Caloryst symbol combines a plate-shaped C and a separate portion segment.
The primary asset is [assets/logo.png](../assets/logo.png), a generated raster
PNG with transparency. It is not an editable vector source.

Generated with the built-in ImageGen tool. Prompt:

> Use case: logo-brand. Create one final standalone logo symbol for Caloryst, an open-source calorie counter. Concept: a bold, distinctive capital C formed by a circular plate rim with a single separated rounded portion segment in the opening. Minimal geometric flat graphic, thick balanced silhouette, rounded ends, one deep emerald green ink with a small warm coral portion accent. No lettering, no slogan, no extra icons, no leaf, no flame, no utensils. Front-facing, centered square composition with comfortable margins, transparent background. Must be legible as a small GitHub README logo and app icon at 16, 32, 64px. No mockup, no gradients, no shadows, no texture, no watermarks. Produce only the symbol.

The generated artwork has slight tonal variation. Trademark availability has
not been researched.
